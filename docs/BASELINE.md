# 版本基线与验收

## 主分支单文件读取（2026-11-23）

单文件通过 `etx_bridge.py` 读取。站点配置选择剪切板和可选 Runner，调用工程配置自己的读取范围与回执目录。用 `resume` 按原请求号回查。[配置和自建 Runner 模板](CONFIGURATION.md#单文件读取) · [路由和回执](ROUTING.md)

Windows 隔离回归 119 项，116 项通过，3 项因平台条件跳过。现有站点用剪切板和已有 Runner 工作流读取同一份合成文件，双路原请求和 SHA256 校验通过。新 Runner 模板用合成证书通过本机加密回执兼容验证。

## 0.3.1

双端升级增加旧接收器检测、定向重载和 Windows 端的版本核对。版本验证读取实际应答的接收器。升级和旧版交接步骤见[运维说明](OPERATIONS.md#双端升级)。

本机合成回归共 113 项，110 项通过、3 项因平台条件跳过。覆盖旧接收端的模拟重载，以及版本与发布摘要匹配、缺失或不一致时的处理。真实 ETX 双端升级以及升级后的普通粘贴仍待各站点验收。

## 0.3.0（2026-11-18）

- Windows 端统一排队。同一会话中的多个调用依次收发，排队超时保留原请求及回执。
- 图片和文字共享 30 秒保护，连续复制会重新计时。支持普通 Windows 截图的本地暂存与恢复，静默期满后沿原请求继续。
- 等待回包期间停止定时重写。接收端只对同一通信包回写一次，回复绑定本次请求。新上传默认 32 KiB 分块，已准备的分块保留原请求内容。
- [升级步骤](OPERATIONS.md#从-020-升级到-030)说明如何同步更新两端并继续使用原 Worker 和任务。

Windows 合成回归和修正后的定向复测共覆盖 112 项，109 项通过，3 项因平台条件跳过。接收端的 7 个离线回放通过。在独立 Windows 剪贴板用合成截图验证了再次复制后重新计时、按原请求继续和截图恢复。

## 0.2.0（2026-11-16）

本次增加单文件及单批总计 256 MiB 的 UTF-8 流式读取/上传、下载断点恢复、首错/末尾日志摘录和本地日志用后清理。每批仍限十个精确文件、每块最多 256 KiB，PDF/Office 的只读 16 MiB 上限不变。小文本上传保留对旧端点的兼容；大文件必须由端点声明支持。

Windows 本机完整合成套件共 103 项，100 项通过、3 项因 Linux/符号链接权限条件跳过。已验证真实 256 MiB 文本快照，Python 跟踪堆峰值低于 8 MiB；覆盖超过 16 MiB 的上传及备份/恢复、校验失败拒绝、加密最大块往返、断点恢复、日志摘录和清理。发布文件与哈希清单经过检查，无站点路径或密钥内容；本项目没有仪表盘构建步骤。

此次仅发布代码和部署说明，未升级或重启现有 ETX 接收端/Worker，未运行 EDA 仿真。保留现有 Worker 的维护方案见 [运维说明](OPERATIONS.md#升级文件能力时保留现有-worker)；实际站点仍须完成原生检查和同通道多块往返验收。Worker 编译/结果目录一节只说明内部绑定 flow，外部使用者可忽略。

## 来源部署已经确认

- 一个长期文件端点、五个 Terminal Worker；真实单路和五路合成任务通过。
- 64 KiB UTF-8 文本往返及字节/SHA256 校验通过；已完成波形的根、定点值和变化查询通过。
- 本地批量客户端 17 项检查、五条各一秒的真实合成派单和批量结果取回通过。
- 同样五次只读控制查询：原逐条调用 22.52 秒，优化后逐条 14.56 秒，批量 8.64 秒。单次中位数 3.88 → 2.48 秒。小样本结果，不代表仿真计算加速或延迟保证。

这些来源验收不携带账号、主机、业务路径、实际证书、日志或波形数据进入发布包。

## 分享版增加的内容

账号、目录、Python、队列、权限与后端设置集中到私有配置；运行时代码保留一份；Windows 客户端不再从旧 Runner 客户端导入清单。初次安装生成每人自己的身份，日常用短命令启动。

分享版新增初装、配置验证和站点适配属于新的代码路径。本机 Windows/Python 3.13 的完整隔离回归共 87 项：85 项通过，2 项平台相关跳过（Linux 初装与 POSIX 符号链接检查）。Windows 新副本的初装、私有目录、真实合成身份生成及公钥引导包排除私钥检查已通过。发布清单和逐文件摘要检查通过。

仓库 CI 在 Linux/Windows 上运行同一套合成测试；不接入 ETX，不运行商业 EDA。没有用另一账号的新 ETX 会话验收，不能宣称所有用户克隆即可零配置运行。
